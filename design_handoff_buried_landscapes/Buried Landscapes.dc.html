Buried Landscapes
A small studio tool for generative ambient MIDI. Every frame below is the same live component, so you can click, type, drop files and run inside any of them. The standalone prototype is Studio.dc.html.
Design decisions
Settings left, result right. The result sits next to the controls and replaces itself on each run. Settings are never cleared, so changing one value and running again is a single step.
Errors at the field. Invalid input is flagged inline as you type where possible (numerals, ranges, file type). The result panel also lists every problem, so nothing is missed.
Reference tools are live. BPM sync and Scale explorer update as you type. They have no Run button.
Schema-driven settings. Each tool is a list of fields: select, number, slider, toggle, multi, text, file, plus custom blocks (progression, transforms). Adding a script means adding one entry.
